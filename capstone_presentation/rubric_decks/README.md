# Capstone presentations

Both decks contain 12 slides including the cover.

- `Edzel_Dela_Cruz_Capstone_Technical.pptx`: editable technical deck with native charts and tables. Speaker notes contain methods, sources and assumptions.
- `Edzel_Dela_Cruz_Capstone_Technical_Slides.ipynb`: Jupyter slideshow version with self-contained slide attachments and presenter notes. Its visual slides are rendered from the editable PowerPoint companion.
- `Edzel_Dela_Cruz_Capstone_Technical.slides.html`: self-contained technical viewing copy. Open locally and use arrow keys to present. Notes are available through the Notes button. No internet connection is required.
- `Edzel_Dela_Cruz_Capstone_Business.pptx`: editable business deck covering capacity, value, risks and pilot strategy.

The financial examples use hypothetical USD assumptions. They illustrate break-even conditions and do not establish actual ROI or prevention benefit.

For Jupyter slideshow export, use Jupyter/nbconvert's slides exporter or a slideshow extension. Edit chart values and layout in the PowerPoint companion. The analysis notebooks 01–06 remain separate from these presentation files.
